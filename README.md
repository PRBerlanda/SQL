# SQL – MySQL

Part of the [SQL](https://github.com/PRBerlanda/SQL) study repository. Each database lives in its own branch.

| Script | Database | What it covers |
|---|---|---|
| `Starting_on_MySQL.sql` | `loja`, `livraria` (created by the script) | `CREATE DATABASE/TABLE`, `INSERT`, filters (`BETWEEN`, `LIKE`), `ORDER BY`, `DISTINCT`; foreign keys; joins and aggregations on a bookstore; views; first procedures (`IN` parameters) |
| `Working_with_data.sql` | `insight_places` | Rental-platform analysis: occupancy rate per property and owner, average daily price by state, rentals per month and region; derived tables; procedures with parameters; a view of owner metrics |
| `Functions.sql` | `insight_places` | Built-in functions (`CONCAT`, `TRIM`, `SUBSTRING`, `DATEDIFF`, `CASE`); user functions (`DELIMITER`, `DECLARE`, `SELECT ... INTO`): average rating, occupancy, CPF formatting, rental info, discount by length of stay; table `resumo_aluguel` |
| `Procedures.sql` | `insight_places` | The `novoAluguel_*` procedure evolves step by step: default values, parameters, computed price, `EXIT HANDLER` for foreign-key errors (1452), `IF`/`CASE`, `WHILE` loop counting weekdays, nested procedures, temporary tables and a cursor |
| `Triggers.sql` | `insight_places` | `AFTER INSERT` trigger that fills `resumo_aluguel` with the discount and final value of each new rental |

## How to run

Use MySQL 8 with MySQL Workbench or the `mysql` client. Run each script from top to bottom; they use `DELIMITER` for functions, procedures and triggers.

- **`Starting_on_MySQL.sql`** creates its own databases. The bookstore data (`autores`, `generos`, `livros`, `comentarios`) can be loaded with the `INSERT` scripts generated by the notebook [`ETL_Exporting_to_SQL`](https://github.com/PRBerlanda/Python-Data-Focused-/blob/main/ETL_Exporting_to_SQL.ipynb).
- **The other four scripts** need the `insight_places` database from the Alura course: owners, customers, addresses, properties, rentals and reviews. The dump is not stored here.
  - Run `Functions.sql` before `Triggers.sql`, because the trigger uses `CalcularDescontoPorDias`, `CalcularValorComDesconto` and the `resumo_aluguel` table.
- **Missing helper procedures.** `Procedures.sql` also calls `calculaDataFinal_01`, `inclusao_cliente_43`, `calcula_preco_total`, `inclui_usuarios_lista` and `looping_cursor`. They were created during the course but are not in the file, so the procedures `novoAluguel_33` onward need them first.

## Changes from the original scripts

- **`Queries1.sql` removed:** it was an exact copy of the first part of `Starting_on_MySQL.sql`.
- **SQL Server script moved.** `Queries2.sql` is T-SQL (`GO`, `IDENTITY`, `FULL JOIN`), so it moved to the [`SQL-Server`](https://github.com/PRBerlanda/SQL/tree/SQL-Server) branch.
- **`Starting_on_MySQL.sql`:**
  - the table name `produtosclientes` was fixed to `produtos`;
  - `drop table comentarios` is now commented out, because the views and the procedure that follow use that table.
- **`Working_with_data.sql`:**
  - `drop procedure if exists` was inside a `DELIMITER $$` block, so it was sent together with `CREATE PROCEDURE` and failed;
  - the view uses `CREATE OR REPLACE`.
- **`Functions.sql`:**
  - `CalcularValorFinalComDesconto()` used `AluguelID` without declaring it and was called with an argument. It now takes `AluguelID INT`.
  - `drop function insight_places.tipoHospedagem` had no `;`. It and the other drops now use `IF EXISTS`.
  - Two syntax templates (`nome_da_funcao`, `funcao`) that broke the script are now comments.
  - `InfoAluguel` and `TipoHospedagem` return `VARCHAR(200)`. The 50-character limit was too short for the concatenated text: in strict mode MySQL raises "Data too long".
- **`Triggers.sql`:** the final value was computed with `CalcularValorComDesconto(new.cliente_id)`. It now uses `new.aluguel_id`.
- **`Procedures.sql`:**
  - `novoAluguel_28` and `novoAluguel_29` inserted the rental when the name matched **several** customers and refused it when it matched exactly one. The conditions were swapped back.
  - `novoAluguel_30` declared `vDataFinal` as `INTEGER`; it is now `DATE`.
  - Two variable-name typos were fixed (`vMEnsagem`, `vNumCLiente`).
  - Stray `;` lines after `DELIMITER ;` were removed.

> **Not run:** no MySQL server was available in this review. The scripts were checked statement by statement with a SQL parser and reviewed by hand.
